# Contribuições

Pull requests são avaliados pelo mantenedor, que decide caso a caso se entram ou não.

- Altere só `src/`. A pasta `dist/` é gerada pelo build.
- Sem dependências de terceiros: tudo em JS/CSS puro, rodando nos navegadores atuais.
- Rode `php tools/build.php` antes de enviar; o build valida a minificação.
- Descreva no PR o que mudou e por quê.
- Ao contribuir, você concorda que o código segue a licença MIT do projeto.
